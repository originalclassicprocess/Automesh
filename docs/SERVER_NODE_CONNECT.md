# Серверная нода и подтверждение управления

Рабочий код, ещё не отметка о публикации сайта.

В настройках добавлены отдельные разделы «Ноды» и «Коннект».
«Ноды» объединяет текущую отправку, собственный ящик и сохранённые панели
управления. Успешное подтверждение администратора добавляет закладку в
зашифрованные настройки именно этого профиля. Закладка сама не даёт прав,
не открывает подключения и не содержит cookie/кодов/ключей. До 12 панелей.
При разных nodeId на одном URL показывается конфликт; автоматический вход
не выполняется. Удаление закладки не отзывает права и не удаляет очереди.

«Коннект»: приглашение почтового профиля, управление своей нодой, либо
отдельно только сигналинг. Адрес/QR принимаются явно; проверка выполняется
по кнопке. Вход по ссылке подтверждения требует диалога и сверки кода.
Нужна доверенная сессия для сохранения списка между открытиями приложения.
У каждой отдельно установленной ноды свой администратор: регистрация у
центрального владельца Automesh не нужна. При первом запуске владелец
получает код из закрытого управления своей установки; будущий установщик
может показывать тот же код без ослабления протокола.

Настройки → Подключения → Серверы подключения: явные WSS-адреса и QR
для LAN и интернета. Настройки сохраняются внутри профиля; до шести
пользовательских серверов каждого типа. Собственные интернет-серверы идут
перед адресами сборки; последние можно отключить. Резервные одновременные
подключения включаются отдельным переключателем.

В своей ноде разрешены явные канонические HTTPS origins, включая публичные.
Остались проверки TLS, nodeId, подписи, коротких кодов и отказ от redirects,
путей, credentials, query-токенов. Новая привязка добавляет WSS-сигналинг ноды.
Режим «Только LAN» исключает публичный сигналинг и публичные HTTP-запросы
очередей/ящиков/привязки/подтверждения администратора. Он не отзывает
ранее загруженные конверты на удалённой ноде и не заменяет системный firewall.

Администрирование — отдельное явное подтверждение из разблокированного
профиля. URL только открывает диалог, не подписывает запрос автоматически.
Смена профиля, блокировка, отмена и истечение запроса останавливают подпись.
Сверяются HTTPS-домен, nodeId и код сверки. Seed/пароль не отправляются.
Same-origin BroadcastChannel переносит запрос в уже открытую вкладку
профиля, без передачи ключей, пароля или сессии ноды.

Первый администратор назначается с отдельным bootstrap владельца сервера;
код привязки почтового профиля для этого не подходит. Управление не
переходит другому профилю при удалении одной из восьми привязок.

Это не мост разных сигналингов и не node-to-node доставка. Для отложенного
получения нужны ранее обменянные ключи и разблокированный клиент получателя
на том же сигналинге, где работает пересыльщик.
