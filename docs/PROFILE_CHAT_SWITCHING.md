# Переключение чатов профилей — 0.1.6, 2026-10-05

Релиз переключения профилей. Обязательная миграция старых аккаунтов и чатов
не входит в условия выпуска; существующие данные не удаляются автоматически.
Опубликован: `v0.1.6-62651a94a40ba39e`, исходники `552167b`. GitHub CI и
штатный SSH-деплой успешны; дополнительных проверок сайта после деплоя не было.

Добавлено в рабочие исходники:

- Выбор профиля в шапке, пароль общей связки вводится заново при переключении.
  Новые чаты используют адрес/подписи выбранного профиля, не адрес владельца.
- Отдельный ключ зашифрованной истории из производного материала каждого профиля;
  существующий ключ и архив старого аккаунта не меняются. Контакты, файлы,
  настройки сети и одноразовые ключи доставки раздельны. Нода должна отдельно
  настраиваться для каждого адреса; чужие привязки не копируются автоматически.
- Название профиля остаётся локальной организационной меткой. Оно не становится
  автоматически публичным ником; новый профиль начинает с пустым публичным ником.
- Сначала проверяются новый адрес и история. Старый транспорт и контроллеры
  останавливаются, записи завершаются, история сохраняется. Затем целевая
  история читается повторно: при обновлении того же профиля нельзя принять
  устаревшую копию из предварительной проверки. Только после этого принимается
  новый контекст. При ошибке чтения/записи прежний контекст остаётся доступен.
- Один выбранный профиль подключён к сети. Остальные не поддерживают фоновые
  соединения. Общий ящик не подписывается на сигналинг, не показывает QR/ссылку
  собственного адреса и не отправляет отметки о прочтении.
- В общем ящике отображается сохранённая история разрешённых источников, с
  названием профиля у каждого чата. Это снимок: его нужно явно обновлять.
  Истёкшие/отозванные разрешения скрывают источник; импорт не оживляет права.
  Во view-модель не передаются настройки ноды или закрытые ключи доставки.
- Сводка ограничивает отображение, а не хранение: 20 чатов на странице,
  50 сообщений на чат, текстовый предпросмотр до 1000 символов. Есть страницы
  чатов и переход к более ранним сообщениям; загрузка другой страницы требует
  повторного пароля. Полные тексты доступны в профиле-источнике, архив не обрезается.
  История пока хранится одной шифрованной записью на профиль: при чтении она
  временно расшифровывается целиком, но в сводке остаются только ограниченные
  публичные поля. Полноценное постраничное чтение с диска требует новой схемы
  хранилища и ещё не реализовано.
- Для ответа/вложений нужно перейти в профиль-источник. Автоматический выбор
  личности для ответа и одновременный приём всех профилей не включены.
- После блокировки и перезагрузки открывается выбранный профиль. Выбор хранится
  в отдельной базе `automesh-private-profile-selection-v1`: отдельный HKDF-ключ,
  AES-GCM, случайный IV и AAD с областью владельца/ревизией, атомарная CAS-запись.
  ID выбора не сохраняется открытым в localStorage и не входит в резервную копию.
  При архивировании/удалении выбранного профиля открывается локальный главный,
  а не прежний публичный адрес. Повреждение записи не выдаётся за отсутствие:
  вход останавливается без перезаписи данных. Экстренное стирание очищает и выбор.
  Без сохранённого выбора сохраняется совместимость со старым личным аккаунтом.
  Общая блокировка вкладок держится на владельце всей связки.
- Переключение отклоняется во время передачи, сохранения или с непустым
  черновиком, чтобы не терять данные. Дочерние профили доступны в доверенном
  режиме. Для временного режима сначала переключиться на прежний аккаунт.
- Резервная копия и управление связкой всегда используют владельца сейфа,
  а не текущий дочерний адрес. Экстренное стирание охватывает все профили;
  обычное удаление истории касается текущего профиля.

Проверки выпуска: 508 тестов / 86 файлов прошли, Svelte/core без ошибок;
production-сборка, PWA и HTTP/signaling прошли. Production возвращает
404 для нового `/dev/profile-chats`, как и для остальных закрытых тестовых страниц.

Браузерная проверка 2026-10-05: `/dev/profile-chats` на loopback, отдельные базы
по UUID запуска, публичные вымышленные ключи, без настоящего сейфа/ноды/транспорта.
Проверены сохранение отдельной заметки в двух профилях, неверный пароль с видимой
ошибкой, смена адреса и отсутствие чужой заметки, возврат к старой истории,
блокировка/разблокировка, перезагрузка с сохранённым выбором, локальность главного,
модальное окно на ширине 390 px и закрытие через Escape.
Пароль `public-test-password` относится ТОЛЬКО к этому тесту, не к `/`.

Это проверка настоящих компонентов переключателя/сводки и модулей контекста на
изолированных шифрованных историях, НЕ полный end-to-end тест корневой страницы.
Дополнительно автоматическая интеграция настоящего ChatService проверяет два
дочерних адреса против независимых собеседников: шифрованную переписку,
аутентификацию и подтверждения. В транспортных кадрах нет адреса владельца/главного.
Тест офлайн-конверта проверяет привязку одноразовых ключей и подписей к дочернему
адресу, расшифровку получателем и отказ при подмене другим профилем.
Используется управляемый транспорт в памяти: это НЕ проверка реального WebRTC,
роутера или работающего ПК-узла. Проверка переписки и независимых привязок нод
на настоящих устройствах остаётся пользовательской приёмкой после деплоя.
Реальные iOS/Android в этой итерации не проверялись; проверена мобильная ширина.
