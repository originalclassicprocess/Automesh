# Проверка 0.0.5

Проверяйте разрушительные функции только на тестовом аккаунте/отдельном origin
и профиле браузера. Сначала сохраните резервную копию. Не очищайте данные
нужной переписки ради проверки. Обновите все открытые вкладки/PWA до 0.0.5.

1. Заблокируйте аккаунт. Неверный пароль не открывает его; исправьте поле на
   верный — аккаунт открывается без «Войти». Проверьте ввод, вставку, автозаполнение,
   Enter и отмену вводимой попытки. Верный автозаполненный пароль означает вход
   без дополнительного подтверждения — это намеренное поведение, не второй фактор.
2. Настройки → Память: обновите размеры; отправьте/примите несколько изображений,
   аудио, видео и документ. Объём и список должны измениться. Скачайте один файл.
3. Отмените очистку: ничего не должно пропасть. Удалите один тестовый файл:
   остальные доступны, в чате есть отметка удаления; повторное предложение
   не загружает его автоматически. Очистите одну категорию, затем всю историю:
   контакты/блокировки/настройки сохраняются. Перезагрузите, проверьте результат.
4. В недоверенном режиме блокировка сохраняет временную переписку. Очистка
   файла из старого доверенного архива не должна сохранять новую временную
   переписку на диск. Перезагрузка по-прежнему требует восстановления аккаунта.
5. «Файлы и медиа»: автополучение по умолчанию включено. Принятый контакт
   отправляет изображения/аудио/видео/документ — они принимаются без кнопки.
   Выключите настройку: новые предложения требуют ручного принятия.
   Незнакомый/заблокированный отправитель не получает права автоматической загрузки.
6. Видео видно прямо в чате, стартует без звука, вне экрана/скрытой вкладки
   приостанавливается. Звук включается вручную. Если браузер запрещает запуск
   или не поддерживает кодек, работают ручное ▶ или скачивание.
7. 🔥: проверьте отмену на обоих шагах. На одноразовом тестовом origin выполните
   финальное подтверждение. Другие обновлённые вкладки того же origin/профиля
   должны выйти. После перезагрузки нет входа по паролю/старой истории/вложений.
   Не должно быть сообщения об успехе при ошибке очистки. Другие устройства,
   профили, origin и скачанные копии не стираются. Новая загрузка приложения
   потребует доступного сайта. На диске остаётся только несекретный маркер сброса
   среди управляемых приложением пользовательских записей; браузерные следы
   не гарантированно уничтожены.

Все автопроверки идут на изолированных временных данных. Production smoke
проверяет HTTPS/версию/CSP/WSS, но не заменяет реальный проход на iPhone/Android.
