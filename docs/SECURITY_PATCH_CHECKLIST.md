# Ручная проверка 0.0.4

Используйте тестовые аккаунты и сохранённую резервную копию. Недоверенный выход
по умолчанию удаляет историю; не проверяйте его на нужной переписке.
После подтверждённой публикации: Настройки → Приложение → Проверить обновления
→ Обновить приложение. Закройте старые вкладки/PWA; проверьте версию 0.0.4.

1. **Существующий доверенный аккаунт:** разблокировать прежним паролем;
   Account ID, история, контакты и вложения должны остаться. Заблокировать и
   разблокировать; затем перезагрузить и снова войти тем же паролем.
2. **Вторая вкладка:** в том же браузерном профиле открыть точно тот же адрес
   сайта и попытаться разблокировать тот же аккаунт. Должно появиться сообщение,
   что аккаунт уже открыт. Блокировка первой вкладки не снимает запрет.
   Закрыть первую вкладку: во второй теперь должен работать вход. В другом
   браузере/инкогнито/origin отдельное хранилище — запрет не обязан действовать.
3. **Переписка:** Chrome ↔ Safari или два разных браузера; принять запрос,
   отправить текст, изображение и короткое аудио в обе стороны. Блокировка /
   разблокировка / перезагрузка должны позволять снова установить соединение.
4. **Смена пароля:** в тестовом аккаунте сменить пароль; после блокировки новый
   работает, старый — нет. Старый файл резервной копии по-прежнему открывается
   своим старым паролем и даёт тот же Account ID. Файл не содержит историю.
5. **Недоверенный режим:** восстановить отдельный тестовый аккаунт; переписка
   переживает блокировку/разблокировку, но новая сессия после перезагрузки требует
   восстановления, а не входа по паролю. Убедиться, что выбран правильный режим.

Сейф v1 обновляется до v2 при разблокировке. Возврат серверных файлов к 0.0.3
не вернёт сейф в v1: старому клиенту потребуется seed/резервная копия. История
и идентификаторы не меняли формат. При ошибке не очищайте данные браузера:
сообщите версию, браузер, этап и текст ошибки, без seed/паролей/сейфа.

Автоматические проверки криптографии не заменяют этот проход реальных
браузеров. Статус аудита: `AUDIT_2026-10-02.md`.
