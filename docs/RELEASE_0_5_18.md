# Automesh 0.5.18

- Open the local AI chat from the chat list. Send a message and receive the
  reply in its own bubble. The chat uses recent exchanges as context and
  stores its transcript in encrypted history on a trusted device.
- Choose an imported GGUF model in the AI chat header. The selection is
  saved for that conversation and the previous engine is released on switch.
- Use Saved Messages for notes and attachments. Existing messages remain
  available there.
- Manage AI model files in the general Storage Manager. View stored GGUF
  sizes, ONNX caches and the model loaded in the current tab. Release the
  runtime or remove the selected browser copy independently.

See [Account AI](ACCOUNT_AI_V1.md) for local files and offline setup.
