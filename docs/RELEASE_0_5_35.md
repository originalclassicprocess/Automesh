# Automesh 0.5.35

Group messages use the same reactions, emoji picker, and message actions
as personal chats. Senders can edit their own text in place. Replies, search,
and forwarding use the updated text.

Each participant can pin one message and remove or replace their pin. The
chat shows a single row with the total. Open it to browse the pins and
select one to jump to its message.

Group actions sync over encrypted connections and use the existing node
queue for eligible offline contacts. Actions on earlier messages are
available when the current group is covered by the original audience.
