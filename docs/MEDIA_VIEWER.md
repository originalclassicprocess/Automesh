# Просмотр фото/видео и аудиоплеер

Фото, GIF и видео открываются в одном полноэкранном просмотрщике. Стикеры
отмечены в существующих метаданных: их нет в общей галерее, но нажатие
на отдельный стикер по-прежнему открывает его отдельно. В карточке контакта
есть отдельная категория «Стикеры». Текстовые эмодзи не являются вложениями.

Кнопки «В мои стикеры» и «Запросить набор» убраны из пузыря стикера в чате.
При открытии стикера они находятся в нижней панели просмотра и в меню «⋯».
Запрос доступен только для входящего стикера с ID набора от принятого контакта.
Сохранение/запрос не закрывает просмотр; результат отображается в панели.
Добавление целого ZIP-набора и ответы на запросы набора остаются в чате.
Стикер в чате отображается без цветного пузыря и рамки медиа; выделение и
подсветка сообщения сохраняются. В просмотре нет сплошной подложки за стикером:
виден затемнённый размытый чат. Альфа-канал PNG/WebP/GIF сохраняется; фон,
нарисованный в самом изображении, автоматически не удаляется.

- Медиа заполняет доступный экран, сохраняя пропорции, без обрезания.
- Счётчик и название поверх медиа; закрытие в верхнем углу с учётом safe area.
- Боковые зоны листания занимают высоту между верхней панелью и нижними
  видеоконтролами. Стрелки и панели исчезают через 3,5 секунды.
- Скрытые боковые зоны продолжают листать, не возвращая панели. Нажатие
  по картинке скрывает/возвращает управление; на видео возвращает его.
- На сенсорном экране — горизонтальный свайп, на клавиатуре — стрелки.
  Нативный видеоплеер сохраняет свои клавиши перемотки при фокусе.
- Свайп вниз по медиа закрывает просмотр, вверх открывает нижнюю панель:
  «Скачать», «Поделиться», «Переслать», «Ответить», «Показать в чате». Последнее
  закрывает просмотр, прокручивает чат к сообщению и подсвечивает его на 1,8 секунды.
  На компьютере и без жестов
  та же панель открывается кнопкой «⋯». Пока она открыта, таймер скрытия выключен.
  Escape сначала закрывает панель действий, затем просмотр. Жесты на самой
  панели и нижней полосе видеоконтролов не переключают и не закрывают медиа.
  Двухпальцевые жесты не считаются свайпом; масштабирование остаётся браузеру.
- Действия используют существующие операции сообщения. Для внешней отправки
  файл сначала проверяется, затем нужен отдельный явный клик для системного
  меню передачи (в частности на iOS). Ответ и пересылка закрывают просмотр.
- «О файле» открывает информацию в той же нижней панели: название, MIME-формат,
  размер (также точно в байтах), дата сообщения и отправитель с адресом.
  Это сохранённые метаданные сообщения, не дата создания исходного файла.
  Назад/Escape возвращает к действиям; закрытие панели оставляет медиа открытым.
- Escape и системная кнопка «Назад» закрывают просмотр; пролистывание внутри
  галереи не добавляет отдельный уровень истории для каждого файла.
- Видео не запускается автоматически со звуком. Встроенное видео в чате
  при открытии галереи/MP3 останавливается, чтобы не играть одновременно.

Аудиофайлы открываются в одном общем плеере под шапкой приложения: квадратная
кнопка паузы (позиция сохраняется), продолжение, перемотка, время, предыдущий/
следующий трек и закрытие. На узком экране переходы между треками находятся
в панели очереди. Поддерживаются разрешённые форматы из media-preview.ts
(MP3, WAV, OGG/Opus, M4A, AAC, FLAC, аудио WebM); возможность воспроизведения
конкретного кодека определяет браузер.

Очередь привязана к исходному чату, включает только доступные локально файлы
и обновляется при получении/удалении. Голосовые записи с именами VoiceMessage
voice-YYYY-MM-DDT… остаются встроенными. Переход между чатами, в список чатов
или настройки не размонтирует плеер; выбор другого исходного чата заменяет
его очередь. Смена трека внутри очереди сохраняет настройки плеера.

В панели очереди транспортные кнопки по центру, под ними полоска перемотки,
прошедшее/полное время и номер трека. Режимы переключаются значками без текста:
порядок ↓ (по умолчанию от свежих к старым) → ↑ (от старых к свежим) →
перекрёстные стрелки (перемешивание); повтор — серый круговорот (выключен) →
зелёный (все) → зелёный с единичкой (один). Текущее состояние доступно в
подсказке и экранному диктору. Ниже — громкость и отключение звука.
Перемешанный порядок сохраняется
между переходами: новый файл добавляется, удалённый убирается, прошлые треки
повторно не разыгрываются. Без повтора очередь останавливается в конце;
повтор всех возвращает к первому треку. Ошибка файла не запускает цикл повторов.
При неподдерживаемом программном управлении громкостью появляется подсказка
использовать кнопки устройства. Настройки относятся к текущему сеансу плеера.

Меню «⋯» у каждого трека: скачать, переслать, поделиться, показать в чате,
информация о файле. Для внешней отправки сначала проверяется файл, затем
требуется отдельное нажатие для системного меню передачи; иначе доступно
скачивание. Пересылка открывает исходный чат и существующий выбор адресата.
Переход к сообщению прокручивает чат и подсвечивает нужное место. Назад/Escape
закрывает панели плеера по уровням, не останавливая музыку.

При открытии видео музыка ставится на паузу, автоматически обратно не запускается.
Голосовые сообщения остаются встроенными в чат и в галерею не попадают.

Для поддерживающих браузеров добавлено Media Session API: управление
воспроизведением средствами ОС, включая название выбранного файла, переход
к предыдущему/следующему треку и перемотку.
Работа при сворачивании вкладки зависит от браузера/ОС: особенно iOS может
приостановить вкладку, и браузерная программа не может обещать фоновую работу
как установленный нативный плеер. Если Safari отклоняет запуск после загрузки,
показывается просьба нажать ▶ ещё раз. Автоблокировка аккаунта остаётся включённой.

Блокировка, выход, смена профиля, удаление играющего файла и закрытие плеера
останавливают музыку и освобождают blob URL/системные действия. Загрузка медиа
по-прежнему проверяет сохранённую длину и SHA-256; внешних ссылок/загрузок нет.
Протокол, формат шифрования, очередь и нода не меняются.
