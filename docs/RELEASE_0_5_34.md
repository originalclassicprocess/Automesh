# Automesh 0.5.34

Group history preserves manual scrolling when new messages arrive or media
previews change size. Photos and stickers keep their layout when preview
bytes are freed after they leave the viewport. Returning to a group restores
the reading position within the open account session.

The group selection toolbar takes a single row, leaving the conversation
available while messages are selected. The group title opens the member list.
The search button uses the same text, date and content filters as personal
chats. Closing search returns to the reading position. Separate history
buttons jump to unread messages or to the latest messages.
