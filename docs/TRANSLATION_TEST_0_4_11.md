# Проверка локального перевода 50/50 — приложение 0.4.11

Файл: `translation-test-50-50-ru.json`, приложен к GitHub-релизу 0.4.11 и подготовлен локально в `.release/`. Содержит 2628 полей: 1314 русских строк и 1314 пустых. Формат — 1; отдельный тестовый язык `ru-XX`, не замена встроенного русского.

1. Откройте **Настройки → Приложение → Язык интерфейса**.
2. Загрузите файл через **Загрузить перевод из JSON**. Выбранным станет **Тест 50/50 · русский + English**.
3. Интерфейс станет смешанным: заполненные поля останутся русскими, пустые покажут английские подписи. Доля 50/50 относится ко всему словарю, не к каждому отдельному экрану.
4. В настройках языка должен быть счётчик **1314 из 2628** (на тестовом языке он может быть по-английски). Перезагрузите страницу: выбор должен сохраниться, если браузер разрешает локальное хранение.
5. Вернитесь к **Русский** или **English**. При желании снова выберите тестовый язык и уберите его кнопкой удаления локального перевода.

Это проверка локальной загрузки, переключения и английского fallback. Она не доказывает качество каждого перевода или работу доставки сообщений. Текст переписки, имена, Mesh ID, названия файлов и сид не должны изменяться. Файл не отправляется на сервер. Пустые поля с подстановками тоже используют целую английскую строку; непустые переводы с повреждёнными подстановками отклоняются.
