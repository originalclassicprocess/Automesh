# Automesh 0.5.26

Private group messages show the sender's timestamp in the viewing device's
local time zone. A message that arrives late goes into its chronological
position and can remain unread even when newer messages have been read.
Older messages with no recorded timestamp retain their existing order.

New and newly recovered incoming messages move the group up in the chat list.
The preview follows send time, and the unread counter and jump button track
individual messages. Local unread markers work with read receipts turned off.
