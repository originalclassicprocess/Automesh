# Automesh: зашифрованная резервная копия аккаунта v1

Файл `.automesh` — JSON с форматом `automesh-account-backup`, версией 1,
KDF `PBKDF2-SHA256`, фиксированными 600 000 итерациями и шифрованием `AES-256-GCM`.
Соль 16 байт, IV 12 байт и ciphertext с 128-битным тегом представлены в canonical
base64. Новые соль/IV создаются `crypto.getRandomValues` для каждого экспорта.
AAD: `Automesh account backup v1:PBKDF2-SHA256-600000:AES-256-GCM`.

В зашифрованном содержимом: версия, derivation `mesh/identity/v1`, BIP-39 seed,
Account ID, ник и время создания. Импорт проверяет словарь/checksum seed,
заново выводит ключ P-256 и Account ID и сверяет его с содержимым. При проверке
копии в открытом аккаунте также требуется совпадение с текущим Account ID.
Адреса/derivation не меняются из-за имени файла Automesh.

Импортируемый файл ограничен 16 КБ, ciphertext — 4096 байт. Неизвестные версии,
алгоритмы, итерации и неправильные длины salt/IV отклоняются до KDF. Файл не
выполняется как код. Ошибки интерфейса не выводят расшифрованное содержимое.

Экспорт требует текущий пароль сейфа. Пароль файла совпадает с ним на момент
экспорта; поздняя смена пароля приложения НЕ меняет скачанную копию. Подбор
пароля возможен офлайн, поэтому важен сильный пароль. Дополнительного фактора
или отдельного пароля файла в v1 нет.

Скачивание не снимает напоминание: пользователь выбирает сохранённый файл
обратно, вводит пароль и подтверждает успешное расшифрование правильного
аккаунта. Нельзя доказать, что файл действительно перенесён на другой носитель.

Интерфейс разделяет подготовку и скачивание: после проверки текущего пароля
и шифрования появляется постоянная ссылка «Скачать файл» и форма обратной
проверки. Нажатие ссылки не скрывает её — скачивание можно повторить. Во время
подготовки виден статус, есть отмена; ожидание ограничено 30 секундами. Уход в
фон отменяет незавершённую подготовку с явным сообщением. WebCrypto-операцию
нельзя принудительно остановить: поздний результат не используется, возвращённая
seed очищается. Неверный пароль или ошибка проверки не подтверждают копию.

Обычное имя `Automesh-YYYY-MM-DD.automesh`. Добавление ника опционально и
выключено по умолчанию: имя файла видно без расшифрования. Содержимое файла
не включает сообщения, контакты, вложения, настройки транспорта или живые
ключи сеанса. Это копия АККАУНТА, а не переписки.

Расшифрованные byte buffers очищаются при завершении/отмене. JavaScript,
WebCrypto, клавиатура, расширения и ОС не дают гарантии очистки всех копий
строк из памяти. Визуальное скрытие seed и запрет штатного копирования не
защищают от подмены клиентского кода или уже скомпрометированного устройства.
