# Сохранённые, ответы и пересылка — 0.0.6

## Поведение и границы

- «Сохранённые» — переписка с собственным Account ID, без сети/сигналинга.
  Текст и полученные локально файлы сохраняются по текущей политике устройства:
  доверенный режим — зашифрованная база, недоверенный — память вкладки. Это не
  синхронизация между устройствами и не резервная копия.
- ↩ у сообщения одним нажатием выбирает ответ. Цитата над вводом отменяется
  крестиком; в отправленном сообщении нажатие на цитату прокручивает к оригиналу.
  Если оригинал есть локально, отображаем именно его содержимое/автора, а не
  произвольную цитату переславшего. Если нет — остаётся присланная выдержка,
  переход сообщает об отсутствии. ↩ N — число ответов в текущей истории чата.
- «Выбрать сообщения»: до 50 сообщений за раз, переслать, удалить у себя,
  скачать. Текст экспортируется в .txt, доступные вложения скачиваются отдельно;
  браузер может спросить разрешение для нескольких загрузок. Экспорт открыт,
  не содержит seed/пароля, но содержит выбранную переписку и публичные Account ID.
- Пересылка: полный список чатов, несколько получателей, до 20 чатов за раз.
  Новому контакту — только одно первое текстовое сообщение/карточка-запрос;
  файлы требуют принятого контакта. Запросы/блокировки не обходятся.
  Принятый файл проверяется по SHA-256 и копируется под новым ID; недоступный
  файл сначала нужно получить. Сохраняются очередь, E2EE и обычный файловый протокол.
  Частичный успех не откатывает уже добавленные сообщения; повтор в открытом
  диалоге пропускает уже выполненное. Отмена/переоткрытие — новая операция.
- ↪ N у исходного сообщения — число уникальных чатов, куда **вы сами** его
  переслали/поставили в очередь. Это не число доставок и не глобальный счётчик:
  автору ничего не сообщается, последующие действия получателей неизвестны.
- Ник-ссылка пересланного автора открывает карточку. Эти сведения указаны
  переславшим, **не являются подписью исходного автора**. Не переносим закрытые
  локальные имена/публичные ключи из своей адресной книги. Ответный контекст
  другого чата при пересылке не переносится.
- «Файлы и медиа → Показывать моё имя при пересылке сообщений» относится к
  новым сообщениям; обновлённые клиенты убирают ник и Account ID из атрибуции.
  Скрытая атрибуция остаётся скрытой при дальнейшей пересылке. Ранее отправленные
  копии, ручное копирование и модифицированные чужие клиенты не контролируются.
- Скрепка предлагает файлы или контакт. Карточка передаёт только Account ID
  и объявленный ник; не делает контакт автоматически доверенным/принятым и не
  утверждает проверку личности. Геопозиция/камера пока не реализованы.
- Удаление — только на этом устройстве. Останавливаем передачи/записи,
  атомарно обновляем историю и убираем выбранные файлы; сохраняем зашифрованные
  отметки ID для защиты от возврата повторной доставкой. Контакты остаются.
  В недоверенном режиме очистка старого архива не записывает новую временную историю.

## Совместимость

Ключи, Account ID, шифрование сеансов и backup-файлы не менялись.
Обычный текст при стандартной настройке атрибуции по-прежнему mesh-chat-v1.
Ответы/пересылка/карточки и отключённая атрибуция требуют mesh-chat-v2 внутри
того же защищённого канала: **обновите обоих собеседников до 0.0.6**.
Старый клиент не получает богатое сообщение; не отправляем небезопасный или
теряющий метаданные запасной вариант. История старого формата читается.

## Проверка пользователем

1. Обновить обе PWA. Без сигналинга открыть «Сохранённые», добавить текст,
   файл и ответ, перезагрузить/разблокировать — в доверенном режиме всё доступно.
2. В обычном принятом чате ответить на текст, изображение, аудио, видео и
   карточку контакта. Проверить цитату, отмену, переход и счётчик ответов у обеих сторон.
3. Выбрать несколько сообщений, переслать двум принятым контактам и в
   «Сохранённые». Проверить новые ID, метку автора, копии файлов, счётчик чатов.
   Отключить соединение — текст должен остаться в очереди и дойти при восстановлении.
4. Скрыть свою атрибуцию, отправить новое сообщение; дважды переслать его.
   На всех обновлённых клиентах в атрибуции нет ника и Account ID исходного автора.
5. Скрепка → Контакт, отправить себе/собеседнику, открыть карточку и новый чат.
   Никакого автоматического принятия запроса или доверия к новому публичному ключу.
6. Скачать выборку/несколько файлов в Chrome/Safari. Отменить удаление, затем
   только на одноразовом тесте подтвердить: выборка/файлы исчезли, остальные
   остались. Повтор доставки не возвращает удалённое, после перезагрузки так же.
7. Заблокировать аккаунт во время обработки; ни поздние результаты, ни чужой
   reset не должны вернуть историю или начать передачу в следующем аккаунте.

Браузерный проход выполнен на отдельном тестовом origin: «Сохранённые» без
сервера, ответ/переход, восстановление истории, пересылка текста/файла себе,
множественная очередь двум недоступным тестовым адресам (счётчик 1 → 3),
карточка контакта, предупреждение/отмена удаления. Завершение скачивания
встроенный браузер не подтвердил; Chrome/Safari и реальная межбраузерная
пересылка остаются ручными проверками. Автотесты используют изолированные данные.
