# Проверка профилей 0.1.5 с домена

Адрес приложения: https://automesh.space/. Тестовый пароль public-test-password
не подходит обычным аккаунтам: используйте собственный пароль.

1. Настройки → Приложение → Проверить обновления → Обновить приложение.
   Убедиться, что версия начинается с v0.1.5-. Данные сайта не удалять.
2. Войти своим паролем. Проверить старый Account ID, контакты и переписку.
3. Настройки → Аккаунт → Профили. Нужен доверенный режим. Ввести свой пароль
   ещё раз и нажать «Открыть управление профилями».
4. Если связки ещё нет, нажать «Создать связку с прежним аккаунтом».
   Если восстанавливаете существующую связку, сначала импортировать её файл.
5. Создать Входящий и Исходящий профили. Проверить различие адресов, переименование
   без изменения адреса, сохранение после выхода из раздела и повторного входа.
6. Выбрать субпрофиль, запросить передачу главному. Выбрать главный и подтвердить.
   Чтение общего ящика отдельно запросить и отдельно подтвердить второй стороной.
   Отзыв одного направления не должен автоматически отзывать другое.
7. Сохранить связку в зашифрованный файл, скачать, выбрать этот файл обратно
   и проверить паролем. Ошибочный пароль должен отклоняться без потери данных.
8. По желанию восстановить файл в отдельном браузерном профиле: сначала выбрать
   доверенное устройство. Проверить те же имена/адреса, отсутствие перенесённых
   разрешений. Это не перенос переписки или ожидающих офлайн-конвертов.
9. Проверить Android/iPhone: поля, прокрутку, скачивание и выбор .automesh файла;
   блокировку/разблокировку. После смены вкладки управление нужно открыть заново.

Переключение списка профилей в настройках пока НЕ переключает текущий чат.
Главный профиль — локальный центр будущего общего ящика, не опубликованный адрес.
Права сейчас показывают разрешённые источники, не саму общую переписку.
Переустановка ноды и локальный запуск серверов для этой проверки не нужны.
