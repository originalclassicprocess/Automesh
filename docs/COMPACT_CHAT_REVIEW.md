# Компактные чаты — локальная приёмка

Релиз 0.2.3: подготовлен к публикации. Статус деплоя — в `UPDATES.md`.
Протокол, seed/ключи, установленная нода и лимиты файлов не менялись.
Остаются 20 МиБ на файл и прежние ограничения очереди/пакета файлов.

## Что изменено

- Шапка: пиксельный аватар всегда виден, рядом ник и название текущего профиля
  в две строки. По нажатию — своя карточка со всеми неархивными профилями
  для общения. Технический корневой адрес не показывается в списке.
  После выбора другого профиля появляется поле `current-password` для
  автозаполнения менеджером паролей. Верный пароль автоматически открывает
  профиль через 700 мс без ввода; кнопка открытия остаётся запасным способом.
  Неверный пароль не закрывает текущий профиль, пароль не сохраняется.
- Пять сетевых состояний на широком экране возвращены в шапку, на узком
  раскрываются в диалоге. Зелёная точка означает
  хотя бы одно соединение (сервер, собеседник или собственная нода), не доставку.
  Выключенные маршруты и отсутствие ключей сами по себе не дают зелёную точку.
- Кнопка «Все чаты»: число непрочитанных сообщений **в других чатах**.
  При выборе сообщений эта кнопка сначала отменяет выбор.
- Нода и запас одноразовых ключей: значок слева от скрепки. Без подключения
  нет постоянного текстового предупреждения; объяснение открывается по нажатию.
  Число ключей не обещает доступность ноды; её точка зелёная только при
  подтверждённой связи. Для старого LAN-ящика доступность не выдумывается.
- Режим выбора заменяет строку собеседника: один чекбокс, счётчик и значки
  переслать/скачать/удалить. Частичный выбор отмечается промежуточным состоянием.
  Удаление по-прежнему требует подтверждения, только на этом устройстве.
- Поле сообщения начинается с одной строки, растёт до ограниченной высоты.
  В области до 380 px кнопки стоят двумя колонками: нода/скрепка слева,
  голос/отправка справа; поле сообщения получает больше ширины.
  Отправка — значок с доступной подписью; текст и кнопки не уменьшены.
- Перетаскивание в область чата: подсветка, отправка при отпускании через
  существующий механизм файлов. Работает только для принятого контакта/
  «Сохранённых», не во время блокировки/смены профиля/выбора/занятых действий.
  Перенос адреса сайта не загружает его. Смена чата во время перетаскивания
  отменяет сброс, а не отправляет файл неожиданному собеседнику.
  Текст черновика остаётся на месте: файл + текст в одном сообщении пока не добавлены.

## Как открыть

Приложение: http://127.0.0.1:5173/.
Для двух независимых тестовых клиентов на одном ПК — также http://localhost:5173/.
Это разные browser origins: у них отдельные аккаунты/хранилища и пароли,
универсального тестового пароля к вашему аккаунту нет. Данные не очищать.

Без входа: http://127.0.0.1:5173/dev/chat — вымышленный компактный чат.
http://127.0.0.1:5173/dev — пример с переключателем мобильной ширины
320/360/390/430 px и примером ноды. Ничего не отправляет/не сохраняет;
перетаскивание в этом примере показывает только названия тестовых файлов.
Обе страницы недоступны в production.
В карточке профилей примера используется только `demo-only-password`.
Это не пароль к приложению или вашим аккаунтам; настоящий пароль туда не вводить.

При подготовке уже запущены Vite 127.0.0.1:5173 и dev-сигналинг
127.0.0.1:3001 в фоне. Это **не** новая установленная нода, не открытые LAN/WAN
порты. Повторно запускать второй Vite на том же порту не нужно.
Если процессы впоследствии закрыты, два отдельных терминала из корня репозитория:

```powershell
npm run dev -- --host 127.0.0.1 --port 5173 --strictPort
```

```powershell
npm run signaling
```

Использовать Node 24+. Для приёмки настоящей офлайн-очереди запускается
ваша установленная нода и используются ранее настроенные привязки.
Сам dev-сигналинг не хранит очередь вместо неё.

## Короткая проверка пользователем

1. Открыть чат без ноды: нет строки-предупреждения, пояснение доступно на значке.
2. Проверить сеть с одним P2P или LAN-соединением и без интернет-сервера:
   зелёная точка есть; без любых соединений — серая.
3. Получить сообщения в другом чате: счётчик на кнопке назад, переход без петли.
4. Выбрать несколько сообщений нажатием на карточки, затем все одним
   чекбоксом и снова снять все. История не должна стать ниже.
5. Проверить пересылку, скачивание, отмену подтверждения удаления.
6. На ПК перетащить 2 небольших файла в принятый чат, затем в «Сохранённые».
   Проверить передачу/очередь и неизменность текстового черновика.
7. Файл больше 20 МиБ должен получить прежнее предупреждение; ссылка,
   заблокированный контакт и смена чата во время перетаскивания не отправляют файл.
8. Длинный черновик, клавиатура/поворот телефона, открытие и закрытие подсказок:
   история остаётся доступной, нет горизонтального выхода за экран.
9. Нажать собственный аватар: все созданные неархивные профили видны.
   Выбрать другой, проверить автозаполнение и автоматический вход.
   Неверный пароль не должен менять текущий адрес. Проверить также отмену.

## Автоматические проверки

623 теста / 103 файла прошли, включая выбор всех/частичный выбор,
счётчик других чатов, сетевую сводку и события drop/отмены/смены получателя.
Svelte: 0 ошибок и предупреждений; TypeScript ядра, production-сборка,
PWA/production smoke проходят, в том числе запрет /dev/chat в production.
В изолированном браузерном примере проверены 320/390 px и desktop,
выбор всех/частичный выбор, закрытие диалогов и ограниченный рост поля до 120 px.
Дополнительно: настоящий компонент выбора профилей с тестовым обработчиком,
автопереход, неверный пароль и отмена до проверки. Проверен загруженный аватар,
две колонки кнопок и широкая строка индикаторов. Реальное открытие профиля
использует прежнее хранилище и guard отмены; менеджеры паролей на устройствах
остаются в пользовательской приёмке.
Шапка выбора не уменьшает высоту истории; горизонтального переполнения нет.
Нативное перетаскивание из Проводника и реальные Safari/Android-клавиатуры
остаются в пользовательской приёмке; браузерный пример не проверяет доставку файлов.
