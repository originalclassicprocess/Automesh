# Automesh 0.5.24

Use the Members button in a private group to invite a contact, remove a member,
or leave. Administrators manage invitations and removals. An administrator
leaving a group with other members chooses a successor. Groups support up to
ten members.

MLS keys update automatically when membership changes. A removal can pause
sending while the remaining members reconnect and confirm the change. Only the
updated membership can decrypt new messages after the change takes effect.

Participants can relay signed updates and help peers recover missed changes
when the original creator is offline. New members begin receiving messages
after joining. Existing message receipts keep the audience from the time of
sending. Update participant devices before testing membership changes in an
existing group.
