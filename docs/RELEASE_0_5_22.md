# Automesh 0.5.22

Private groups now appear among personal chats and LoRa channels. Open a group
in the main conversation pane and find it by name in chat search. Incoming
invitations appear as chat rows with an invitation badge.

Use the pencil button at the bottom of the chat list to choose a contact,
create a private group with up to ten members including yourself, choose a model
for the local AI chat, or open a LoRa channel configured on a connected radio.
Choosing a different AI model keeps the local chat history.

An accepted invitation now requests the MLS keys again when the app resumes
or the participant refreshes the chat. The creator resends the keys even after
an earlier sync from that participant. Group messages still show how many
participants' devices confirmed delivery.
