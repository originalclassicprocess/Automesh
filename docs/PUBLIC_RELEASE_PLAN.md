# Public source and release boundaries

See [public source preview](PUBLIC_SOURCE_PREVIEW.md) and [history](../HISTORY.md).
This repository opens with a clean current snapshot. Operational history and
deployment credentials stay private. Publishing does not deploy a server.

Current priorities: independent security review, mobile/Bluetooth recovery,
clean Linux installation, accessibility, documentation and translations.
App dependency notice/advisory findings remain in the linked review documents.
Public provenance must be verified against each actual downloaded artifact.
Code rollback cannot restore missing keys or reverse state migrations.
