# Проверка интерфейса 0.1.2

1. Открыть https://automesh.space/ → Настройки → Приложение → Проверить
   обновления → применить 0.1.2. Не очищать данные сайта: это удалит аккаунт/историю.
   Узел 0.1.1 можно оставить, настройки пересыльщика не менялись.
2. Открыть чат, затем настройки. Переключить несколько разделов и вкладок связи.
   Назад (кнопка интерфейса, Escape на ПК или системный Back) должен вернуть
   сначала меню настроек, затем прежний чат, не перебирать все вкладки.
3. В чате включить «Выбрать сообщения». Нажать на текст/изображение сообщения:
   появляется рамка выбора, файл не открывается. Нажать снова — выбор снят.
   «Выбрать все» выделяет текущую переписку, «Снять выбор» очищает выделение.
   Проверить пересылку, скачивание и удаление только на тестовых сообщениях.
4. Настройки → Аккаунт: открытый ключ не показан по умолчанию, раскрывается
   отдельной кнопкой. Проверить «?» возле функций и разделов.
5. На Android/iPhone проверить портрет/альбом, клавиатуру, длинный ник,
   безопасные области экрана и доступность отправки. На ПК — широкий чат,
   узкое окно и навигацию Tab/Enter. При необходимости масштабировать страницу:
   масштабирование намеренно не запрещено.
6. Заблокировать/разблокировать, проверить сохранение прежней переписки,
   индикаторы ноды и отложенную доставку. Новый дизайн не увеличивает запас
   одноразовых ключей: для его пополнения нужен обмен с собеседником.

Автоматические проверки не заменяют проверку системных жестов и Safari
на настоящем телефоне. Браузерный пример `/dev` доступен только локально,
не использует аккаунты, ключи, реальную переписку или сохранение данных.
