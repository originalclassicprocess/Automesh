# Changelog

## 0.5.10 — notification timing and selection actions (2026-11-16)

Notify after durable node upload; keep immediate attempt alerts without a node.
Per-device chat mute and foreground suppression work through the optional push
provider. Cancel obsolete queued wakes. Mixed selections support ZIP download,
retry and cancellation; failed LoRa sends support a confirmed bulk retry.
See docs/RELEASE_0_5_10.md.

## 0.5.9 — browser notifications (2026-11-16)

Optional generic Web Push with the built-in app provider, replaceable provider,
signed accepted-contact permissions, and bounded reverse reminders without nodes.
Server Node 0.4.19 can retain a signed wake after courier storage. Existing message
delivery, receipts and status colors remain independent. See docs/RELEASE_0_5_9.md.

## 0.5.3 — public release sources (2026-11-09)

Public node downloads, About project, pinned source compatibility and verifiable release/deployment pipeline. See docs/RELEASE_0_5_3.md. No delivery protocol changes.


## Public source preview — November 2026

Source baseline: app 0.5.2, with compatible dependency/security updates,
contributor documentation and isolated builds. This publication does not
deploy the hosted messenger or replace installed nodes.

## 0.5.2 — 3 November 2026 (pre-publication release)

- Native Meshtastic channel text alongside private Automesh conversations.
- USB/Bluetooth radio integration, radio contact cards and routing per contact.
- Bluetooth reconnection and late receipt/status handling improvements.
- Optional Automesh contact link in channel send options; UTF-8 byte counter.
