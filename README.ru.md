# Automesh

[English](README.md) · [История разработки](HISTORY.md)

Экспериментальный браузерный мессенджер/PWA с локальным хранением. Аккаунт без
телефона и почты; личная переписка через интернет, LAN и короткий текст через
совместимые радиомодули Meshtastic.

**Предварительный выпуск исходников. Независимого аудита защиты ещё нет.**
Разработка идёт с 30 апреля 2026 года. Эта публичная копия начинается с чистого
снимка; старые репозитории и служебная история сохранены приватно.

## Ценности и возможности

Децентрализация инфраструктуры, хранение на своих устройствах и шифрование
личного общения по умолчанию — с привычными удобством и простотой. Домашний
компьютер должен быть практичной нодой без обязательной аренды VPS. Это цели,
а не заявление о готовой автономной глобальной сети.

| Область | Что доступно |
| --- | --- |
| Аккаунт | Без телефона/email; восстановление сидом; локальный сейф с паролем |
| Личные чаты | Шифрованные текст/файлы, голосовые, ответы, пересылка, выделение, вставка картинок, эмодзи/стикеры |
| Связь | Прямой WebRTC при доступности; выбранные сигналинги; подключаемые ноды с зашифрованной очередью |
| Бэкапы | Отдельно доступ, данные или полная копия; ручное восстановление |
| Устройства | Подтверждение владельцем, отдельные ключи, копии новых текстов и ручной перенос истории/вложений; не все функции равны |
| Личный LoRa-чат | Короткий зашифрованный текст Automesh через USB/Bluetooth Meshtastic; без файлов, звонков и групп по радио |
| Каналы Meshtastic | Отдельный интерфейс; отправитель — плата, действуют правила защиты радиосети |
| Интерфейс | Русский/английский, локальные переводы, темы, профили, локальные GIF/стикеры |
| Звонки | Пробные личные голосовые; выбор аудиовыхода зависит от браузера |

Приём нодой, платой, приложением и прочтение — разные состояния. Получатель
должен открыть/разблокировать приложение. Радиоподтверждение не гарантирует
сохранение после перезапуска платы. Общий канал Meshtastic отличается от
личного чата с проверенной идентичностью Automesh.

## Запуск из исходников

Node.js 24, минимум 22.12. Доступы к хостингу не нужны.

```sh
npm ci --ignore-scripts
npm --prefix nodes ci --ignore-scripts
npm run prepare
npm run dev -- --host 127.0.0.1
```

Используйте тестовые аккаунты без настоящих сидов и переписок. Проверки:
`npm run check`, `npm run i18n:check`, `npm run check:core`, `npm test`,
`npm run build`; затем `node scripts/test-pwa-shell.mjs` и
`npm run test:production`. GitHub-проверки не делают деплой.

## Ноды отдельно

[automesh-nodes](https://github.com/originalclassicprocess/automesh-nodes) —
основной проект протокола/ядра и Windows/Linux/server. `nodes/` здесь —
синхронизируемая копия. [Поддержка платформ](nodes/docs/PLATFORM_STATUS.md).

На automesh.online работает 0.5.2; эта публикация исходников не обновляет сайт.
Windows-нода: базовый выпуск 0.4.16; опубликованный ранее Linux/server: 0.4.12.
Новые публичные сборки — кандидаты, а не подтверждение установки Linux.
Нового Windows-подобного мастера у Linux нет; установщика Mac тоже нет.

## Ограничения и помощь

Нет обещаний анонимности, гарантии доставки или завершённого аудита защиты.
Метаданные видны инфраструктуре. NAT, firewall, сон браузера/iOS, очистка
хранилища, квоты и ограничения эфира влияют на работу. TURN не поставляется.
Нужна помощь с защитой, восстановлением Bluetooth, Windows/Linux, доступностью,
переводами, NAT/TURN и ограничением злоупотреблений. Группы, маркетплейс,
витрины, MQTT-мосты и произвольная многошаговая сеть нод пока не реализованы.

В обзоре зависимостей остаются пять записей низкой серьёзности и четыре версии
инструментов сборки/тестов без найденного полного лицензионного текста; в их
манифестах объявлена MIT. Это явно отражено в [обзоре защиты](docs/DEPENDENCY_SECURITY_2026-11-08.md)
и [лицензий](docs/DEPENDENCY_LICENSE_REVIEW.md), а не объявлено исправленным.

Код проекта — [MIT](LICENSE); зависимости сохраняют [свои лицензии](THIRD_PARTY_NOTICES.md).
